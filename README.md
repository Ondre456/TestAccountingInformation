# TestAccountingInformation

Веб‑приложение для учёта запросов на предоставление информации (например, справок 2‑НДФЛ).

## Функциональность

**Для сотрудников:**
* создание запросов на получение различных типов информации (2‑НДФЛ, о стаже и т. д.);
* указание количества документов и комментария к запросу;
* просмотр списка своих запросов и их статусов;
* просмотр деталей запроса.

**Для бухгалтеров:**
* просмотр всех запросов;
* взятие запроса в работу;
* отметка запроса как выполненного;
* отклонение запроса.

**Общая функциональность:**
* регистрация и авторизация пользователей;
* разделение прав доступа по ролям («Сотрудник», «Бухгалтер»).

## Технологии

* ASP.NET Core MVC;
* Entity Framework Core (SQLite);
* ASP.NET Identity для аутентификации;
* Bootstrap для фронтенда.

## Установка и запуск

1. Клонировать репозиторий:
bash
git clone https://github.com/Ondre456/MobileProgrammingLabs.git

2. Перейти в папку проекта
cd TestAccountingInformation

3. Восстановить пакеты NuGet:
dotnet restore

4. Обновить базу данных 
dotnet ef database update

5. Запустить проект:
dotnet run

6. Перейти на страницу 
http://localhost:5244
